# Listagem de Turma

Sistema web para cadastro e gerenciamento de alunos com cálculo automático de média e classificação por desempenho.

## Funcionalidades
- Cadastro de alunos
- Cálculo automático de média
- Classificação (Aprovado, Reprovado, Recuperação)
- Exibição dos dados em tabela
- Contagem de alunos por status

## Tecnologias
- HTML
- CSS
- JavaScript
